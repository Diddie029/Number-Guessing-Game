# 🎯 Number Guessing Game

**PROJECT URL:** https://github.com/Diddie029/number-guessing-game
PROJECT URL : https://roadmap.sh/projects/number-guessing-game
## Project Description
A simple interactive Python game where the computer generates a random number between 1 and 100. The player must guess the correct number within a limited number of attempts.

## Difficulty Levels
- Easy: 10 chances
- Medium: 5 chances
- Hard: 3 chances

## Features
- Random number generation.
- Multiple difficulty levels.
- Hints after incorrect guesses.
- Tracks the number of attempts.
- Displays winning and losing messages.

## Technologies Used
- Python 3

## How to Run
1. Clone the repository.
2. Open the project folder in VS Code or another Python editor.
3. Run the following command:

```bash
python main.py
```
